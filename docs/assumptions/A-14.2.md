# A-14.2

**Assumption.** The page does not remember which game a visitor picked last. Each visit follows `startGame` again.

**Reason.** Remembering means a new `localStorage` key and a rule for when it beats the random start. That is a product choice beyond the issue. The README limits storage to things like a high score.

**Effect if incorrect.** If returning visitors should get their last game, `main.js` stores the picked id and `pickGame` prefers it, behind the same `?game=` pin.

**Validation or mitigation.** Ask the team when ADR-0014 is decided.
