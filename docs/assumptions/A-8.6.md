# A-8.6

**Assumption.** The pnpm settings from plan section 11 (`minimumReleaseAge: 1440`, `saveExact`, `engineStrict`) live in `pnpm-workspace.yaml`, not in `.npmrc`. The repo has no `.npmrc`.

**Reason.** pnpm 11 reads only auth and registry settings from `.npmrc`. A `minimum-release-age` line there is ignored without an error, so the 24 hour wait would silently not apply.

**Effect if incorrect.** If a future pnpm reads these from `.npmrc` again, nothing breaks; the workspace file still applies. Anyone who copies the plan's `.npmrc` into another repo on pnpm 11 gets no release age guard.

**Validation or mitigation.** `pnpm config get minimumReleaseAge` in the repo prints 1440. The README and ADR-0008 point at `pnpm-workspace.yaml`.
