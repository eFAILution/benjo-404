# A-8.4

**Assumption.** The page ships with no audio. Games are designed to be fully readable without sound, and theme packs carry no sound files.

**Reason.** A 404 page is often opened in a work tab. Autoplay audio is blocked by browsers, needs user activation, and adds bytes against a tight budget. Silence also avoids any accessibility work for sound cues.

**Effect if incorrect.** If the owner wants sound, the host context gains an optional `audio` hook behind a visible mute toggle, and packs may add tiny synthesized cues. No existing contract field changes.

**Validation or mitigation.** The owner confirms during review of the first playable game.

**Decision owner.** eFAILution

**Status.** open
