# A-8.4

**Assumption.** Games have sound, with a visible mute toggle. Sound starts only after the player's first input, the mute choice is remembered in `localStorage`, and cues are synthesized with the Web Audio API so no audio files ship.

**Reason.** The owner asked for sound that can be muted. Browsers block audio until a user gesture, and a 404 is often opened in a work tab, so muting must be one tap away. Synthesized cues keep the page within the size budget.

**Effect if incorrect.** If the default should be muted, the toggle starts in the muted state; nothing else changes.

**Validation or mitigation.** Built in a follow-up issue: the host context gains an optional `audio` hook, theme packs may override cues, and the game works fully with sound off.
