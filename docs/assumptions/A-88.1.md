# A-88.1

**Assumption.** Until the real USS Never Sleeps art is available, a stand-in ship drawn from simple shapes is good enough to ship. It is a rear view with swept wings, a hull with an accent stripe, two lit engines, and an open cockpit with Benjo in it.

**Reason.** The owner said the 3D model is at demo.beastcore.com. The public page there is a Vue host that loads a workspace picker ("platform-selector"), and neither has a model file or mentions the ship. The model is probably behind a login. Building the game around a swappable sprite lets it ship now.

**Effect if incorrect.** If the owner wants the real ship before release, `src/games/neversleeps/ship.js` is the only file to change. It needs a rear-view outline in palette colors, the cockpit spot (`COCKPIT_Y`, `PILOT_H`), and maybe `SHIP_ASPECT` in `tuning.js`.

**Validation or mitigation.** Ask the owner for the model file, or two or three reference images from behind and from above, and trace them into `ship.js`. A model can't ship as-is: the page loads nothing after it opens and has a 2D canvas only (ADR-0008).
