# A-8.2

**Assumption.** The project may embed the Benjo mark from `fav-red.svg` (as vector path data) and subset copies of the Inter and Geist Mono fonts in the built page. The font subsets are declared under the internal family names `B404 Sans` and `B404 Mono` so the SIL Open Font License Reserved Font Name rule is respected, and the OFL texts ship in `assets/fonts/`.

**Reason.** The live page already uses the mark and both fonts, and both fonts are published under the SIL OFL, which allows embedding and subsetting if modified versions are not distributed under a Reserved Font Name. The brand owner is the team's own company.

**Effect if incorrect.** If the mark may not be used, Benjo is drawn from an original sprite instead of the logo paths. If the fonts may not be shipped, the font files are dropped and the CSS falls back to the system stack with no code change. Either way the page keeps working.

**Validation or mitigation.** The owner confirms brand use. The fonts' license files are checked before the subsets are committed, and the family rename is applied during subsetting.
