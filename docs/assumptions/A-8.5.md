# A-8.5

**Assumption.** The Benjo sprite in `src/assets/benjo.js` is exempt from the theme sprite rules that `tests/themes/packs.test.js` enforces (a viewBox of 64 to 128 units and path `d` strings under 1200 characters). It keeps the logo's own viewBox `[91, 91, 620, 620]` and the full logo paths. Every other theme sprite still follows the rules.

**Reason.** Benjo is the real logo from `fav-red.svg`. Rescaling or simplifying the paths would change the brand mark, and one of its two paths is 1436 characters long. `drawSprite` scales by `h / viewBox[3]`, so the larger viewBox costs nothing at runtime.

**Effect if incorrect.** If the rules must hold for every sprite, Benjo needs a redrawn, simplified version, which is a brand question for the owner. No shell code changes.

**Validation or mitigation.** `tests/themes/packs.test.js` checks that each pack's Benjo matches the logo viewBox and applies the size rules to the other sprites. The owner confirms the logo may ship as is (see A-8.2).
