# A-8.3

**Assumption.** Holiday selection uses the visitor's local calendar date from the browser clock, covers US federal holidays plus Valentine's Day, St. Patrick's Day, Easter, Halloween, and New Year's Eve, and falls back to the brand default theme when no holiday with a pack is within its window. Holidays with sensitive meaning (for example Memorial Day, Juneteenth, Veterans Day, Martin Luther King Jr. Day) stay in the calendar but get no decorative pack unless the owner asks for one.

**Reason.** Issue #3 asked for "the closest American holiday" with swappable packs. The local date is the only input that needs no network and no personal data. Decorative treatment of remembrance days could read as disrespectful, so they are opt-in.

**Effect if incorrect.** If non-US visitors should see regional holidays, the calendar gains a region switch. If every holiday should have a pack, the pack list grows; no shell code changes.

**Validation or mitigation.** The owner reviews the holiday table and the window sizes in `src/holidays/calendar.js`. `?theme=` and `?date=` query overrides let anyone preview any holiday.
