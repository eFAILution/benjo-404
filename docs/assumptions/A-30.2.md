# A-30.2

**Assumption.** Cache misses are drawn with the theme's hazard sprites, by index (miss *i* uses `hazards[i % length]`). The Clear cache pellet is the first pickup sprite. While catchable, a cache miss is tinted `palette.muted` (gray), and it flashes back to its own colors for the last 1.5 s.

**Reason.** Every theme pack already has hazards and pickups, so no pack needs new art (ADR-0013 made the same choice for Benjo Flight's towers). Packs have no blue token for the arcade's frightened ghosts, and gray reads as "switched off" on every palette.

**Effect if incorrect.** A pack with fewer than four hazard sprites gives two cache misses the same look. The Halloween pack has three, so two are pumpkins. If players can't tell them apart, a pack could add a fourth hazard sprite, or the game could tint each cache miss.

**Validation or mitigation.** Headless screenshots at 1280×800 and 375×740 show the maze, four cache misses, and the pellets in the Halloween pack. Check that the gray state reads in the default and Christmas packs too.
