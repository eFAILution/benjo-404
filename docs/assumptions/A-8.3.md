# A-8.3

**Assumption.** Holiday selection uses the visitor's local calendar date from the browser clock and falls back to the brand default theme when no holiday with a pack is within its window. The calendar should cover a wide range of fun holidays that can reasonably be themed (for example New Year's, Valentine's Day, St. Patrick's Day, Easter, Independence Day, Halloween, Thanksgiving, Christmas, and lighter days such as Pi Day or Star Wars Day). Remembrance days (Memorial Day, Juneteenth, Veterans Day, Martin Luther King Jr. Day) stay in the calendar with no decorative pack.

**Reason.** The owner asked for a wide range of fun holidays that can be reasonably themed. The local date needs no network and no personal data. Decorative treatment of remembrance days could read as disrespectful, so they stay opt-in.

**Effect if incorrect.** If a remembrance day should get a respectful pack, or non-US visitors should see regional holidays, the calendar and pack list grow; no shell code changes.

**Validation or mitigation.** The owner reviews the holiday list in the follow-up issue for more packs. `?theme=` and `?date=` let anyone preview any holiday.
