# A-104.2

**Assumption.** The score is one point per pop across all locks, with no bonus for opening a lock. Load Balancer, which pulls pickups in the other games, widens the hit window by half while it runs. The Digital Twin forgives any one miss: a tap off the target, a tap on a bug (the bug goes), or a run past the target (Benjo turns round to face it).

**Reason.** The issue says the score is total pops and leaves the power-ups to the game. Nothing on the ring moves toward Benjo, so pulling has no meaning here; a wider window helps in the same spirit, an easier next point. Every way to lose is a miss, so the twin treats them all alike.

**Effect if incorrect.** A lock bonus is one line in `open` in `src/games/crackhash/world.js`. If the wider window feels like a different game, drop `magnet` from the module's `powers` and the How to play card.

**Validation or mitigation.** `tests/games/crackhash/powers.test.js` checks each power. Watch whether players notice the wider band when it is played for #19.
