# A-8.7

**Assumption.** Inter and Geist Mono declare no Reserved Font Name in their OFL license files. The subsets are still renamed to `B404 Sans` and `B404 Mono` as a precaution.

**Reason.** The rename costs nothing. It stays correct if a later release adds a Reserved Font Name, keeps the cut-down files from posing as the full fonts, and stops the page from matching a locally installed Inter or Geist Mono by name.

**Effect if incorrect.** If either font does declare a Reserved Font Name, the rename already satisfies the license. If the owner wants the original names, the CSS and the subset step change; no other code does.

**Validation or mitigation.** `assets/fonts/OFL-Inter.txt` and `assets/fonts/OFL-Geist.txt` were read and hold no Reserved Font Name line. `assets/fonts/README.md` records the source hashes.
