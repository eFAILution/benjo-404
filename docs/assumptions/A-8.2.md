# A-8.2

**Assumption.** The project may embed the Benjo mark from `fav-red.svg` (as vector path data) and subset copies of the Inter and Geist Mono fonts in the built page. The font subsets are declared under the internal family names `B404 Sans` and `B404 Mono`, and the OFL texts ship in `assets/fonts/`. Neither font declares a Reserved Font Name, so the rename is a precaution (A-8.7).

**Reason.** The live page already uses the mark and both fonts, and both fonts are published under the SIL OFL, which allows embedding and subsetting. The brand owner is the team's own company.

**Effect if incorrect.** If the mark may not be used, Benjo is drawn from an original sprite instead of the logo paths. If the fonts may not be shipped, the font files are dropped and the CSS falls back to the system stack with no code change. Either way the page keeps working.

**Validation or mitigation.** Confirmed by the owner on 2026-10-24. Inside Webflow the page can use the site's own fonts instead of the subsets (A-8.1).
