# A-20.1

**Assumption.** With nine games, the game over card offers only two other games, the next two after the current one in config order (wrapping), plus an "All games" button that quits to the idle screen and its picker. The order is fixed so testers see the same card for the same game.

**Reason.** One "Play <name>" button per other game gave eleven actions on the card with nine games. On a 320x568 phone that pushes Return Home below the fold, and on a 320x240 landscape phone the card clipped. Two switches plus "All games" keep the card at five actions, and the picker already lists every game one tap away.

**Effect if incorrect.** If players want a random or "least played" suggestion, or more than two switches, `nextGames` and `OVER_SWITCH_MAX` in `src/shell/boot.js` change; the card itself scrolls, so a third switch still fits.

**Validation or mitigation.** `tests/shell/boot.test.js` pins the cap and the wrap. Headless Chromium screenshots of the card at phone and desktop sizes. Watch for feedback that players never find the other games.
