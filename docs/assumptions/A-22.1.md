# A-22.1

**Assumption.** Progress lives only in the visitor's browser. A save code is enough for the few players who want to move it to another device, so there are no accounts and no server.

**Reason.** The page has no backend, must hold no personal data, and is visited briefly. A save code keeps the whole feature static.

**Effect if incorrect.** If players want real sync, it needs a server and a login, which is a new decision. The save code format has a version byte, so it can grow without breaking old codes.

**Validation or mitigation.** `tests/shell/save-code.test.js` covers the round trip, tampered codes, and merging. Restoring only raises values, so a wrong code cannot wipe progress.

**Status.** open
