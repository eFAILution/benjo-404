# A-8.1

**Assumption.** The page lives inside Webflow, on the site's 404 utility page. The game ships as inline Code Embed elements, each under Webflow's 50,000 character limit, and uses the fonts the site already loads. The single `dist/404.html` with a hashed CSP stays as a standalone preview and test target.

**Reason.** The owner confirmed beast-code.com is built and hosted on Webflow, so nothing sits in front of it to swap the 404 response. Since May 2024 Webflow allows up to 50,000 characters per Code Embed and per page custom code field. Today's embed build is 42,638 characters of JS and 8,095 of CSS, so it fits, but sound, more holidays, and more games will not fit in one embed.

**Effect if incorrect.** If the 404 utility page cannot hold Code Embeds or custom code, the script must be hosted on another origin and referenced from the page, which adds a network request and a supply chain dependency.

**Validation or mitigation.** Add an embed to the 404 utility page on a staging copy of the site and publish it. A Webflow build target splits the bundle into several embeds and fails the build if any exceeds 50,000 characters. Webflow sets the response headers, so the strict CSP header does not apply there; the code itself still makes no network requests.
