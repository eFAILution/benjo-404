# A-20.3

**Assumption.** Sound is on by default, quiet (a master volume of 0.18), and only plays during a run. The mute button sits in the run's HUD next to pause, and M mutes from anywhere on the page. All nine games share ten named cues instead of each game shipping its own sounds.

**Reason.** A-8.4 asked for sound with a mute one tap away. Browsers keep sound off until the player taps or presses a key, and the idle page makes no sound, so a visitor who never plays hears nothing. Ten shared cues keep the shell small (a cue is a few tones) and let a theme pack restyle every game at once.

**Effect if incorrect.** If sound should start muted, `createAudio` reads the stored choice and defaults to on; flipping that default is one line. If a game needs a sound none of the cues fit, a new cue name goes in `AudioCue` and `CUES`.

**Validation or mitigation.** `tests/shell/audio.test.js` covers the unlock, mute, theme override, and no Web Audio cases. `tests/shell/host.test.js` covers the end of run cues. Phones in silent mode play no Web Audio sound, so try it with the ringer on.
