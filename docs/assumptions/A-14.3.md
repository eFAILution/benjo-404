# A-14.3

**Assumption.** The picker lists games by their `name` and in the order of `games` in `benjo.config.json`. The game over card offers every other bundled game, one button each.

**Reason.** Config order is the one order the team already controls. With two to four games a row of buttons fits the card. A longer list would need a menu, which no one has asked for.

**Effect if incorrect.** With five or more games, the card should show one "Switch game" button that opens the picker instead.

**Validation or mitigation.** Revisit when a third game is added.

**Decision owner.** eFAILution

**Status.** open
