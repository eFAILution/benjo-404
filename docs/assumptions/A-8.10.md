# A-8.10

**Assumption.** Benjo Run hitboxes and ground placement use each sprite's measured drawn area, inset 12% on each side and 8% from the top, instead of the plain viewBox box from plan section 9.

**Reason.** Theme art has empty margins inside its viewBox. A viewBox box makes hazards hit before they touch and makes sprites float above the ground line.

**Effect if incorrect.** If hits feel unfair, the insets in `src/games/runner/tuning.js` change. No other code does.

**Validation or mitigation.** `tests/games/runner/sprite-bounds.test.js` checks the measured bounds. Play with each theme and watch near misses.
