# A-13.4

**Assumption.** Benjo Flight keeps Benjo and every gap below the HUD strip. The game uses its own ceiling, 64px from the top of the canvas or 96px under 600px wide, which mirrors `--strip-h` in the shell CSS (56px, 88px under 600px since #17) plus a small margin.

**Reason.** The HUD strip covers the top of the canvas during a run. `HostContext` has no field for the covered area, and issue #13 adds a game without changing the shell or the contracts. Benjo Run never flies that high, so the gap did not show until now.

**Effect if incorrect.** If the HUD height changes, Benjo can hide behind it, or the play area wastes space. The fix is to change `CEILING` and `CEILING_NARROW` in `src/games/flight/tuning.js`.

**Validation or mitigation.** A follow-up can add a safe top inset to `Size` in `src/contracts.d.ts`, so every game reads it from the host instead of copying the CSS value.
