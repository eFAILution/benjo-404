# A-24.1

**Assumption.** On the paused card, Play again and the game wheel end the current run straight away, with no "are you sure" step. The run's score is dropped, not saved as a best. Spinning the wheel only chooses a game; pressing the game in the middle starts it, and pressing the current game starts it from zero. With `gamePicker: false` the card shows Resume, Play again, and Quit only.

**Reason.** A 404 page's runs last seconds, so a confirmation step costs more than the run it protects. The wheel works the way it already does on the start screen (#20), so players learn it once. A paused run never reached its end, so saving its score would let a player bank a best by pausing.

**Effect if incorrect.** If players lose good runs by mistake, Play again could ask first, or the paused score could count toward the best. If the wheel is too big for the card on small phones, the card could show the next two games as buttons, like the game over card.

**Validation or mitigation.** Host tests cover the restart. Headless Chromium at 375, 768, and 1280px wide showed the card, the wheel switch, Play again, and Quit working, with the wheel inside the card. Play-test it on a real phone.
