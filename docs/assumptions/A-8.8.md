# A-8.8

**Assumption.** Three build details differ from the first design of the build and are kept. `tsconfig.json` uses `module: ESNext` and `moduleResolution: Bundler` and checks only `src/`. The test script is `node --test 'tests/**/*.test.js'`. The content rules of `build/check.js` live in `build/check-content.js`, which `check.js` re-exports.

**Reason.** Bundler resolution matches how esbuild resolves the page's imports. `node --test tests/` on current Node treats the folder as a module path and fails, so the quoted glob is needed. The split keeps both check files under 300 lines.

**Effect if incorrect.** If `build/` and `tests/` should be type checked too, `include` grows and some JSDoc may need fixing. Nothing changes at runtime.

**Validation or mitigation.** `pnpm run lint` and `pnpm run test` pass with these settings. ADR-0008 is updated to match.

**Decision owner.** eFAILution

**Status.** revised: the test script now quotes the glob with double quotes, so it also works where pnpm runs scripts through `cmd.exe` (A-32.1).
